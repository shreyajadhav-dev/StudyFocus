# Study Focus — UpStart Interns Task 01

A simple one-screen SwiftUI app that reacts to user interaction.

## Requirements covered

- `@State` drives the view
- At least two controls: Stepper, Toggle, and Button
- UI reacts immediately to user actions
- Designed to run in the iOS Simulator
- Single-screen SwiftUI implementation

## Features

- Adjust study duration from 5–120 minutes
- Turn Focus Mode on/off
- Start and stop a study session
- Visual UI changes when the state changes

## How to run

1. Open `StudyFocus.xcodeproj` in Xcode on a Mac.
2. Select an iPhone Simulator.
3. Press Run (▶).
4. Try the Stepper, Toggle, and Start/Stop button.

## Design decision

The project intentionally stays small and focused on the task requirements rather than adding extra screens or features.
